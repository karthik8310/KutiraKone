KutiraKone – Zero Waste Fabric Exchange App

KutiraKone is an Android application developed to reduce textile waste by connecting tailors, boutique owners, and artisans through
a local fabric scrap exchange platform. The app allows users to upload leftover fabric pieces, browse available scraps, and request swaps, 
helping promote sustainability and community collaboration.

Features:
User Registration & Login
Upload Fabric Scrap Details with Images
Browse Available Fabric Listings
Real-time Data Sync using Firebase Firestore
Image Storage using Firebase Cloud Storage
Material-based Listing Display
Modern Android UI with Material Design
Secure Firebase Authentication

Technologies Used:
Android Studio
Kotlin
XML
Firebase Authentication
Firebase Firestore
Firebase Cloud Storage
Glide
Material Design Components
ConstraintLayout
AndroidX Libraries
Gradle Kotlin DSL

Project Objective:
Many tailors and boutique owners discard leftover fabric scraps due to the absence of a proper reuse platform. 
At the same time, artisans struggle to find affordable small fabric pieces for patchwork and craft work. 
KutiraKone solves this issue by creating a digital platform for exchanging and reusing excess fabric materials.

Installation Steps
Clone the repository:
git clone https://github.com/karthik8310/KutiraKone.git
Open the project in Android Studio.

Connect Firebase to the project:
Firebase Authentication
Firebase Firestore
Firebase Storage

Run the application on an Android device or emulator.
